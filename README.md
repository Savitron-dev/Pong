## 🧐 About The Project

This project is a high-performance, polished implementation of the legendary **Pong** game. Built with clean, modular code, it offers smooth physics, responsive paddle controls, and retro-inspired visual elements.

Whether you're looking to challenge a friend locally or test your skills against an AI opponent, this repository provides an engaging arcade experience right out of the box.

## ✨ Key Features

* 🎮 **Smooth Controls:** Zero-latency paddle movement for precision gameplay.
* 🤖 **AI / Local Multiplayer:** Play against a smart AI bot or a friend on the same keyboard.
* ⚡ **Dynamic Physics:** Ball speed gradually increases with every successful rally.
* 🎨 **Retro Aesthetic:** Clean minimalist UI with neon arcade styling.
* 📱 **Responsive Design:** Auto-scales to fit different display sizes smoothly.

## 🎮 Gameplay \& Controls

|Player|Move Up|Move Down|
|-|-|-|
|**Player 1 (Left)**|<kbd>W</kbd>|<kbd>S</kbd>|
|**Player 2 (Right)**|<kbd>▲ Up Arrow</kbd>|<kbd>▼ Down Arrow</kbd>|

* **Pause / Resume:** <kbd>Spacebar</kbd> or <kbd>P</kbd>
* **Reset Game:** <kbd>R</kbd>

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have a web browser installed (Chrome, Firefox, Edge, or Safari).

### Installation

1. **Clone the repository:**

```bash
   git clone https://github.com/Savitron-dev/Pong.git
   ```

2. **Navigate into the project directory:**

```bash
   cd Pong
   ```

3. **Run the game:**

   * Simply double-click `index.html` to open it in your default web browser.
   * *Or* run a local server (e.g., using VS Code's Live Server extension).
